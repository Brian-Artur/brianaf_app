This is a small project done in Vue to test the refactoring and test cases of a counter component.📈

## How to run the project

```bash
npm install
npm run dev
```

## Test cases

- `+` increments the counter.
- `-` decrements the counter.
- The counter cannot go above 10.
- The counter cannot go below 0.
